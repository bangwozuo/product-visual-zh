# 文案排版

把卖点文案排进画面：给出版式结构、栅格坐标、字号层级与配色方案，脚本画出栅格示意图
并做量化检查。主图在手机列表页只有 150–200px 宽——版式的全部目标是**在 3 秒滑动里
让一个利益点被看清**。

不做的事：不产出成品图、不让生图模型画汉字、不替文案做合规判断（交给合规预审）。

## 能力描述

1. **栅格系统**：8px 基准网格、12 栏（栏距 16px）、安全边距 = 短边 6%（小红书 8%）、
   黄金区（上 1/3 至中线左 2/3）放主卖点，卖点图走 Z 型动线、详情模块走 F 型。
2. **文字层级**：三级封顶——主标题 ≥画布宽 5%（800 基准 40px）、副标题 ≥3.5%、
   卖点条 ≥3%（24px，缩略比 4:1 下中文可读底线）；主标题 ≤9 字，辅助卖点 ≤2 条。
3. **量化检查**（脚本 `grid_preview.py` 实测，不靠感觉）：
   字号达标 / WCAG 对比度（正文 ≥4.5:1，大标题粗体 ≥3.0:1）/ 文字面积
   （抖音 ≤20%，淘宝/天猫主图除 Logo 外禁文字）/ 安全边距 / 商品区重叠。
4. **平台红线**：淘宝主图禁文字（牛皮癣）→ 利益点移第 2–5 张；主图 5 张结构
   （首图钩子 → 2–3 细节 → 第 4 参数 → 第 5 场景）。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `product` | string | ✅ | 商品名 |
| `platform` / `purpose` | string | ✅ | 平台与用途（主图/商品卡/详情模块），决定文字面积上限 |
| `canvas` | string | ✅ | 画布尺寸，如 `900x1200`、`800x800` |
| `bg_color` | string | ✅ | 背景色 hex，对比度按它实测 |
| `product_zone` | object | ⬜ | 商品区 {x,y,w,h}；文字块不得与其重叠 |
| `blocks` | array | ✅ | 文字块列表：level（title/subtitle/bullet）/text/x/y/w/size/color/bold |

## 使用步骤

### 方式一：纯提示词（拿版式方案）

1. 把 `prompt.txt` 全部内容粘贴为系统提示词
2. 提供卖点文案 + 平台用途 + 画布尺寸
3. 得到版式结构、文字块坐标与排版提示词（文字后期用设计工具加，不让模型画汉字）

### 方式二：带脚本（栅格示意图 + 量化检查）

```bash
python3 <SKILL_DIR>/scripts/grid_preview.py --input examples/input.json --outdir out
python3 <SKILL_DIR>/scripts/grid_preview.py --demo          # 无输入也能看效果
```

**分工**：脚本做**栅格绘制与量化检查**（字号/对比度/面积/边距/重叠）；模型做**版式选型、
删字与排版提示词**。两边结论交叉核对，检查不过按整改指令改坐标后重跑。

## 边界（不做的事）

- ❌ 栅格示意图不是成品图——成品由设计工具按坐标制作
- ❌ 不让生图模型生成汉字/Logo（必出错别字），只留区域后期加字
- ❌ 淘宝/天猫主图方案不出现 Logo 之外文字；图上文案先过 `platform-compliance-precheck`
- ❌ 不给"放大一点/换个颜色"类空话，改法必须带具体坐标、字号、色值
- ❌ 数值以脚本输出为准，不自己估

## 调用示例

**输入**（`examples/input.json`）：便携电热水杯，抖音商品卡 900×1200，3 个文字块。

**输出**（脚本实跑，退出码 0）：判定**需整改**——字号 FAIL（卖点条 22px < 底线 27px）、
对比度 FAIL（卖点条 3.15:1 < 4.5:1）、安全边距 FAIL（三个文字块 x=48 侵入 54px 边距）；
文字面积 10.2%（≤20% 达标）、商品区无重叠。整改指令见 `examples/output.md`，
栅格示意图见 `out/版式栅格示意图.png`。
