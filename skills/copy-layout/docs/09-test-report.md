### 检查明细（examples/input.json 实跑）

| 检查项 | 结果 | 实测 |
|---|---|---|
| 字号 | ❌ FAIL | 卖点条 22px < 27px 底线（3% × 900） |
| 对比度 | ❌ FAIL | 卖点条 3.15:1（WCAG 实测）< 4.5:1 |
| 文字面积 | ✅ PASS | 10.2% ≤ 20%（抖音商品卡上限） |
| 安全边距 | ❌ FAIL | 文字块 x=48 < 54px 边距 |
| 商品区重叠 | ✅ PASS | 无 |

判定**需整改**——demo 数据故意带缺陷，用于验证 FAIL 路径与整改指令生成；
主标题 12.56:1、副标题 7.86:1 的 PASS 路径同轮验证。

### 质量核对

| 检查 | 结果 |
|---|---|
| 对比度算法 | WCAG 相对亮度比（线性化 sRGB），非 RGB 欧氏距离 |
| 淘宝主图禁文字 | platform=淘宝 + purpose=主图 → 任何文字块即 FAIL（面积上限 0%） |
| 中文渲染 | msyh.ttc 优先，回退 simhei/Deng/arial，PNG 中文正常 |
| FAIL 路径 | 字号/对比度/边距/重叠四类 FAIL 均有对应整改指令生成 |
