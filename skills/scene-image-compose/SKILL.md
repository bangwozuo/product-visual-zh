# 场景图合成

把白底商品图放进真实使用场景：输出**合成提示词包**（场景 + 光影四参数 + 透视参数 +
商品锁定）。合成的生死线只有两条——**商品要接受场景的光，视角要和背景同机位**。

不做的事：不产出图片本身、不让商品自带"棚拍光"进场景、不合成虚假使用效果。

## 能力描述

1. **场景选型**：按商品类型给高转化场景与雷区（厨房用品配"烹饪进行时"，个护配
   大理石+水珠+柔光；避雷样板间、顶灯直射）。
2. **光影一致四参数**：光源方向（与场景主影子同侧）、色温（晨光 ≈3500K / 正午
   ≈5500K / 黄昏 ≈3000K / 阴天 ≈6500K）、光比（2:1–3:1，暗面不死黑）、
   接地阴影（方向与光源反向）。
3. **透视一致**：机位高度、镜头焦段（50mm 眼平起步）、灭点匹配（视角差 >15° 换背景）、
   景深（商品在焦平面，背景 f/2.8 轻虚化）。
4. **商品锁定**：优先「白底图图层贴回 + AI 背景光照融合」兜底；纯生成时颜色 hex、
   材质、结构词原样进正向词，负向词防改色/改形/改 Logo。
5. **验收清单**：光影/透视人眼四查 + 颜色 ΔE00<3.0、结构差异 ≤2% 交
   `product-fidelity-check` 实测。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `product_info` | string | ✅ | 白底图描述、材质（金属/玻璃/哑光/透明）、主色 hex、尺寸感 |
| `requirement` | string | ✅ | 场景与情绪（厨房清晨/户外黄昏…）、平台与画布（800×800 / 900×1200 / 750×750） |
| `composition` | string | ⬜ | 构图偏好：商品占比 40%–60%、朝向留白方向 |

## 输出规格

- `strategy`：图层贴回 / 纯生成式，及选择理由
- `positive_prompt` / `negative_prompt`：完整可复制提示词（含色温数值与机位锁词）
- `light_params`：方向 / 色温 / 光比 / 接地阴影
- `perspective_params`：机位 / 镜头 / 景深
- `lock_terms`：商品锁定清单（属性 → 策略 → 验收方式）
- `qc_checklist`：出图后验收清单
- `compliance_notes`：AI 标识、肖像与第三方品牌注意项

## 使用步骤

### 方式一：纯提示词（最快）

1. 把 `prompt.txt` 全部内容粘贴为系统提示词
2. 提供白底图描述 + 场景要求
3. 得到提示词包 → 在图像工具执行 → 按验收清单逐项过

### 方式二：接入工作流

```bash
# 出图后的量化验收交给保真校验脚本
python3 ../../product-fidelity-check/scripts/fidelity_check.py --real 白底图.png --gen 场景图.png --outdir out
```

完整链路见 `product-image-batch-qc-flow`：白底图生成 → 场景合成（本技能）→ 保真校验。

## 边界（不做的事）

- ❌ 不产出图片本身，不承诺合成效果
- ❌ 不给商品配第二种光——光源方向、色温在方案里必须是唯一值
- ❌ 有 Logo / 关键纹理的商品不走纯生成式合成（改走贴回方案）
- ❌ 场景不放无授权人物、第三方品牌、竞品；不制造虚假使用效果（夸大容量/尺寸）
- ❌ 不暗示合成图为实拍；不编造用户没给的商品属性

## 调用示例

**输入**（`examples/input.json`）：不锈钢摩卡壶，白底图，厨房晨光场景，抖音 900×1200。

**输出**（节选，完整见 `examples/output.md`）：图层贴回策略；光影参数
方向 upper-left / 色温 3800K / 光比 2:1 / 接地阴影朝右下；透视 45° 俯拍 + 50mm +
f/2.8 背景虚化；正向词含 ` brushed stainless steel, hex #8C9296, subtle reflections
of warm kitchen`；验收清单 4 项。
