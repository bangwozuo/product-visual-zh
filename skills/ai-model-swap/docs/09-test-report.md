## 五、边界与已知限制

| 限制 | 说明 |
|---|---|
| 不产出图片 | 本技能只交提示词包；出图效果取决于用户所用图像工具对参数的支持程度 |
| 参数非万能 | 不同图像模型（SD 系 / MJ / 即梦 / 可灵）参数名与取值范围不同，投喂前需按工具映射 |
