# 使用示例

以下输入均为真实业务场景数据；本技能为纯提示词资产（T2），输出为提示词包示例。

---

## 示例 1：挂拍图换街景上身（抖音 3:4）

**输入**：

```json
{
  "product_info": "法式碎花连衣裙：藏青底小雏菊碎花（图案直径约 8mm），面料人造棉（哑光垂坠感），方领泡泡袖、A 字中长裙，左下摆处有刺绣小 Logo「LUMI」",
  "requirement": "目前只有挂拍图，无真人素材；目标平台抖音商品卡，需要 3:4 比例；换成亚洲女模特，正面自然站姿，午后街景背景"
}
```

**输出要点**：路线 B（ControlNet OpenPose + IP-Adapter 0.8），1024×1536，DPM++ 2M Karras 30 步 / CFG 7。
锁定词 `navy blue, hex #1F3A5F` / `ditsy daisy floral print, flower scale 8mm` / `viscose rayon, soft matte drape`；
刺绣 Logo 不进正向提示词，出图后按左下摆原图贴回（2–4px 羽化）。
完整提示词包见 `examples/output.md`。

**合规注意**：抖音发布开启"内容由 AI 生成"声明；不得作买家秀。

## 示例 2：真人原图只换背景（淘宝主图）

**输入**：

```json
{
  "product_info": "男士纯棉 Polo 衫：燕麦色（hex #D3C6B0），珠地网眼面料，三粒扣门襟，左胸无 Logo，平肩常规版型",
  "requirement": "已有真人上身图（模特已授权），只想把室内影棚背景换成户外庭院景，衣服与模特完全不动；出淘宝主图 800×800"
}
```

**输出要点**：路线 A（局部重绘），**蒙版只涂背景**，模特与衣物全部留在蒙版外；
Denoising 0.60–0.75，蒙版羽化 8–12px，出图 1024×1024 后中心裁 800×800（商品占比保持 ≥80%）。
锁定词 `oatmeal beige, hex #D3C6B0, pique cotton knit, three-button placket`。
因衣物不在重绘区，商品本体漂移风险接近零，仅需验收第 1 项（颜色）与第 6 项（接缝——
人体轮廓与背景过渡带无色阶断层）。

## 示例 3：格纹衬衫从零生成（小红书 1:1）

**输入**：

```json
{
  "product_info": "复古格纹法兰绒衬衫：红黑格纹（格宽 25mm，对缝对齐），全棉法兰绒（表面起绒），翻领双胸袋，常规剪裁，无 Logo",
  "requirement": "只有平铺图；出小红书笔记配图 1:1，换模特，坐姿咖啡馆场景，画面需留 20% 顶部空间放标题文字"
}
```

**输出要点**：路线 B，负向提示词必须追加 `mismatched plaid, seams not aligned, pattern drift`
——格纹对缝是法兰绒衬衫最常见的 AI 重排翻车点；坐姿骨架手部关键点缺失时**放弃该姿态**
（换手部清晰的坐姿骨架）。构图要求在正向词尾部加 `top 20 percent clean space for title text`。
出图后第 2 项（格纹对齐）为重点验收项，量化判定交给 `product-fidelity-check` 结构差异块占比（≤2% 为过）。

**合规注意**：小红书配图不得含二维码/微信号；标注 AI 生成。

## 示例 4：不接单的请求（对照组）

**输入**：

```json
{
  "product_info": "白色纯棉 T 恤",
  "requirement": "帮我把这件白 T 的颜色 P 成薄荷绿，再让模型把面料画成真丝质感，就当新款卖"
}
```

**输出要点**：**拒绝并说明理由**——改颜色、改材质等于生成了另一款商品，成品与实物不符
会触碰《广告法》第 28 条虚假宣传，且保真校验（ΔE00、材质语义比对）必然不合格。
正确路径：若确有薄荷绿新款，用**薄荷绿实物的原图**走换装流程。
