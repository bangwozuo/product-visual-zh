# AI 模特换装

把平铺图/挂拍图/真人原图变成一套**可执行的换装提示词包**。换的是模特和背景，
不是商品——颜色、材质、版型、Logo、图案一项都不许漂。

不做的事：不产出图片本身、不承诺出图效果、不让模型"画 Logo"。

## 能力描述

1. **路线选型**：按素材形态选局部重绘（最保商品）/ ControlNet + IP-Adapter（无真人图）/
   分部位分层合成（高客单价兜底）三条路线之一，给出去噪强度、蒙版羽化、参考图权重的分档参数。
2. **商品本体锁定**：把颜色（含十六进制参考）、材质织法、版型结构词、图案比例、Logo 策略
   逐项写成正向锁定词 + 负向反向锁定。
3. **参数规格**：分辨率按平台给（3:4 1024×1536 出图后裁 800×800 / 1000×1000 / 750×750），
   采样器 DPM++ 2M Karras 28–35 步，CFG 7±1。
4. **出图后质检清单**：六项验收（颜色/图案/Logo/版型/手部/接缝），量化判定移交
   `product-fidelity-check`（ΔE00 < 3.0 为过）。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `product_info` | string | ✅ | 商品信息：品名、颜色（有 hex 更好）、材质、版型结构、图案（格纹/碎花/印花及比例）、Logo 位置与内容、实物图描述 |
| `requirement` | string | ✅ | 生成要求：现有素材（平铺图/挂拍/真人图）、目标平台与尺寸、换什么（换模特/换背景/换姿势） |
| `model_brief` | string | ⬜ | 模特要求：性别、年龄段、体型、拍摄角度；不填按类目主流客群给 |

## 输出规格

- `route`：推荐路线（A/B/C）与选择理由
- `positive_prompt` / `negative_prompt`：可直接复制的完整提示词
- `params`：分辨率 / 采样器 / 步数 / CFG / 去噪强度 / 蒙版羽化 / IP-Adapter 权重
- `lock_terms`：商品本体锁定清单（属性 → 锁定词 → 风险提示）
- `qc_checklist`：出图后六项质检表（合格线 + 不合格处置）
- `compliance_notes`：AI 生成标识、平台尺寸、禁虚构买家秀等注意项

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开任意支持自定义提示词的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供商品信息 + 生成要求
4. 得到换装提示词包 → 在图像工具中执行 → 按质检清单验收

### 方式二：接入工作流

```bash
# 出图后的量化验收直接交给保真校验脚本
python3 ../../product-fidelity-check/scripts/fidelity_check.py --real 实物图.png --gen 换装图.png --outdir out
```

提示词包产出后，图上若还要加利益点文字，先过 `platform-compliance-precheck` 再交 `copy-layout`。

## 边界（不做的事）

- ❌ 不产出图片本身；实际出图由用户在图像工具执行
- ❌ 不让模型生成 Logo 文字与品牌名拼写（必然拼错）——走贴回原图或后期合成
- ❌ 不提供"改变商品本体"的方案（改色/改材质/改版型）——那是另一款商品
- ❌ 不暗示 AI 图为真人实拍，不用于虚构买家秀，不提供规避 AI 检测的技巧
- ❌ 不编造商品颜色、材质、图案——用户没给的列清单索取

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "product_info": "法式碎花连衣裙：藏青底小雏菊碎花（图案直径约 8mm），面料人造棉（哑光垂坠），方领泡泡袖、A 字中长裙，左下摆刺绣小 Logo「LUMI」",
  "requirement": "只有挂拍图，无真人素材；出抖音商品卡 3:4；换亚洲女模特，正面自然站姿，街景背景"
}
```

**输出**（节选，完整见 `examples/output.md`）：推荐路线 B（ControlNet OpenPose + IP-Adapter 0.8），
1024×1536，DPM++ 2M Karras 30 步 / CFG 7；正向提示词含锁定词
`navy blue dress, small ditsy daisy floral print, scale 8mm, viscose, matte drape,
square neckline, puff sleeve, A-line midi`；Logo 走贴回方案；附六项质检与合规注意。
