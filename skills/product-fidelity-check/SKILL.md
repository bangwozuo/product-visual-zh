# 产品保真校验

在商品图发布前，把 AI 生成图与实物**逐项对齐**，用可复核的数字判定「能不能上架」。

不做的事：不写卖点、不做美化、不重出图。只出**返工指令单**。

## 能力描述

以实物标准图为基准，对生成图做五项量化校验，输出可直接执行的返工定位：

| # | 指标 | 口径 | 合格线 |
|---|---|---|---|
| 1 | 长宽比偏差 | \|AR_gen − AR_ref\| / AR_ref | ≤ 1.0% |
| 2 | 主色 ΔE00（最大） | CIEDE2000，前 3 主导色配对取最大 | < 3.0 |
| 3 | 边缘扩散宽度 | 轮廓外法向「仍带商品色」像素数的均值 | ≥ 0.5 px |
| 4 | 结构差异块占比 | 16×16 块平均色差 > 40 的块占比 | ≤ 2.0% |
| 5 | 主体面积变化 | \|前景占比差\| / 基准前景占比 | ≤ 1.0% |
| 6 | 语义级比对 | Logo 字形 / 纹理 / 工艺 / 材质 | 人工确认 |

判定三级：✅ 合格 / 🟡 警告 / 🔴 不合格；任一 🔴 即整体**需返工**。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `reference_image` | string | ✅ | 基准图路径（实物原图 / 标准图），不得用「上一版 AI 图」 |
| `target_image` | string | ✅ | 待校验图路径（AI 生成图或修图成品） |
| `product` | string | ⬜ | 商品名 / SKU，用于报告抬头 |

CLI 也支持直接传 `--reference` / `--target`。

## 输出规格

| 字段 | 类型 | 说明 |
|------|------|------|
| `verdict` | string | ✅ 通过 / 🟡 有条件通过 / 🔴 需返工 |
| `metrics` | array | 五项指标：实测值 / 口径 / 判定 |
| `color` | array | 主色配对明细（含 ΔE00） |
| `hotspots` | array | 结构差异热点（区块坐标 + 平均色差） |
| `fail` / `warn` | array | 不合格项 / 警告项清单 |

## 使用步骤

### 方式一：纯提示词（拿到判定口径与返工单）

1. 打开任意支持自定义提示词的 AI 工具
2. 把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供基准图与生成图（或各自的尺寸、主色 RGB、差异描述）
4. 得到分级判定与返工指令单

方式一含完整的阈值表、失败模式与改法模板，但数值靠模型判断，**精度有限**。

### 方式二：带脚本（数值精确，产出真实文件）

```bash
python3 <SKILL_DIR>/scripts/fidelity_check.py --input examples/input.json --outdir out
python3 <SKILL_DIR>/scripts/fidelity_check.py --demo            # 无输入也能看效果
python3 <SKILL_DIR>/scripts/fidelity_check.py --reference 实物.png --target 生成.png --outdir out
python3 <SKILL_DIR>/scripts/fidelity_check.py --demo-assets examples/assets   # 只生成示例素材
```

产物：

| 文件 | 内容 |
|---|---|
| `out/保真校验对比图.png` | 基准图 / 生成图 / 色差热力图 / 前景掩膜 四联图 + 指标条 |
| `out/保真校验报告.xlsx` | 校验总览 / 指标明细 / 主色比对 / 结构差异热点（不合格行标红） |
| `out/保真校验报告.md` | Markdown 报告（含返工指令） |
| `out/fidelity.json` | 机器可读结果，供智能体读取 |

**分工**：脚本算**数值**（ΔE00 用完整 CIEDE2000，不用 RGB 欧氏距离）；模型做**语义级比对**
（Logo 字形、纹理、工艺）与返工话术。两者结论应交叉核对。

## 边界（不做的事）

- ❌ 不自己算数值 —— 一切指标以脚本输出为准
- ❌ 不把「AI 图 vs 上一版 AI 图」当保真校验，基准必须是实物原图
- ❌ 不在角度 / 焦距不一致时给长宽比与结构结论
- ❌ 不因"看着差不多"就判通过
- ❌ 不对近纯白主体（白瓷 / 珍珠白）给边缘结论 —— 掩膜会失效
- ❌ 本技能**不能替代**人工比对实物，结论不构成质量鉴定

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "product": "玻璃瓶装精华液 30ml（SKU: SERUM-30ML-001）",
  "reference_image": "examples/assets/demo_ref.png",
  "target_image": "examples/assets/demo_gen.png"
}
```

**输出**（脚本实跑）：

| # | 指标 | 实测值 | 判定 |
|---|---|---|---|
| 1 | 长宽比偏差 | 5.26% | 🔴 不合格 |
| 2 | 主色 ΔE00（最大） | 3.87 | 🟡 警告 |
| 3 | 边缘扩散宽度 | 0.00 px | 🔴 不合格 |
| 4 | 结构差异块占比 | 35.56% | 🔴 不合格 |
| 5 | 主体面积变化 | 4.95% | 🟡 警告 |

整体判定：**🔴 需返工**（不合格 3 项 / 警告 2 项）。完整结果见 `examples/output.md`。

## 合规声明

- 本技能输出为 **AI 辅助校验结果**，像素指标经脚本实测，语义级保真须人工复核
- 保真校验是发布前硬卡点：图与实物不符可能触发《广告法》第 28 条虚假宣传风险
- 请按所在平台要求完成 AI 生成内容标识
- 不因校验结果建议修改商品实质描述以匹配生成图
