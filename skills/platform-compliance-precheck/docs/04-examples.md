## 示例 1：化妆品极限词 + 站外导流（淘宝）

**输入**：

```json
{
  "platform": "淘宝",
  "category": "化妆品",
  "text": "【全网最低价】医美级精华液，100% 彻底淡化痘印，效果最好的抗敏修复神器！国家级实验室研发，独家配方，销量第一。加微信 xxx 领取试用装，扫码进群更优惠。"
}
```

**输出**（实跑，命中 13 项，判定：不建议上架）：

| 级别 | 原文片段 | 命中规则 | 建议改法 |
|---|---|---|---|
| 🔴 红线 | 最低价 | 绝对化用语·最高级 | 限时优惠价 ¥99 |
| 🔴 红线 | 100% / 彻底 | 绝对化用语·功效断言 | 实测反馈良好（样本 30 人） |
| 🔴 红线 | 最好 | 绝对化用语·最高级 | 2026 年新款 |
| 🔴 红线 | 医美级 / 抗敏 | 化妆品·医疗宣称 | 删医疗表述，改「舒缓保湿」 |
| 🔴 红线 | 国家级 | 绝对化用语·级别 | 删除，改用客观参数 |
| 🔴 红线 | 独家 / 第一 | 绝对化用语·唯一性·排名 | 删除；有专利可附专利号 |
| 🔴 红线 | 加微信 / 扫码 | 淘宝·站外导流 | 删除导流信息 |
| 🟡 警告 | 神器 | 营销强化词 | 保留但加限定语 |

**整改后文案**（可直接用）：
> 2026 年新款精华液，限时优惠价 ¥99。配方含神经酰胺，主打舒缓保湿。实测反馈良好（样本 30 人）。

## 示例 3：小红书笔记导流

**输入**：

```json
{
  "platform": "小红书",
  "category": "",
  "text": "姐妹们这个面霜真的绝了！100% 回购，用完皮肤状态超好，加微信 xxx 领小样～"
}
```

**输出**：命中 2 项 —— 🔴「加微信」（小红书·导流，社区规范明令禁止）+ 🔴「100%」（绝对化用语·功效断言）

**整改后文案**：
> 这个面霜已经回购好几次了，用完皮肤状态挺稳定的。想聊聊的姐妹评论区见～
