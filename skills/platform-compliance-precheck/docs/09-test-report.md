## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 只扫文本 | 图片牛皮癣需先 OCR 得到文字再传入（`image_text` 字段） |
| 词表非穷尽 | 覆盖高频违规词；长尾与语境判断依赖模型按 prompt.txt 复核 |
| 平台规则时效 | 词表基于公开规范整理，平台更新后需维护（见 `quality/tracking_log.md`） |
| 语境判断 | 脚本不做语境判断（如「最新款 iPhone」不违规），须由模型复核 |
