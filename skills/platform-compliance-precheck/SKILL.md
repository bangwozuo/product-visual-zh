# 平台合规预审

在商品上架前，把会被平台**下架、限流、扣分**的表述挑出来，并给出**可直接替换的改法**。

不做的事：不写卖点、不写文案、不评判商品质量。只做审查。

## 能力描述

按三类规则做分级合规扫描，输出**可执行的整改清单**：

1. **绝对化用语**（《广告法》第九条）—— 最高级 / 排名 / 唯一性 / 级别 / 功效断言
2. **类目特有禁用词** —— 化妆品、食品、保健品、医疗器械、母婴、教育、金融各有独立禁词表
3. **平台特有规则** —— 主图牛皮癣、站外导流（二维码/微信号）、虚假促销、资质公示

判定分三级：🔴 红线（必须改）/ 🟡 警告（建议改）/ 🔵 提示（需补材料）。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `text` | string | ✅ | 待检文案（标题 + 副标题 + 详情页 + 图上文字，尽量给全） |
| `platform` | string | ✅ | 淘宝 / 天猫 / 抖音 / 小红书 / 拼多多；其他填「通用」 |
| `category` | string | ⬜ | 化妆品 / 食品 / 保健品 / 医疗器械 / 母婴 / 教育 / 金融；不填则只扫绝对化用语 |
| `image_text` | string | ⬜ | 主图上的文字内容（用于牛皮癣判定）；有图可先 OCR 再传 |

## 输出规格

- `summary`：受检平台 / 文本量 / 三级计数 / 整体判定
- `hits`：违规清单（级别 / 原文片段 / 命中规则 / 依据 / 建议改法）
- `need_material`：需补充的证明材料清单

## 使用步骤

### 方式一：纯提示词（最快，任意平台）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 新建对话，把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供待检文案 + 平台 + 类目
4. 得到分级违规清单

方式一由模型按 prompt.txt 内嵌的三类规则判断，含语境判断与误报排除。

### 方式二：带脚本（词表精确扫描 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/precheck.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/precheck.py --demo        # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/合规预审清单.xlsx` | 违规清单（红线行标红）/ 汇总 |
| `out/precheck.json` | 机器可读结果，供智能体读取 |

**分工**：脚本做**词表精确扫描**（不漏、不猜）；模型做**语境判断与改法撰写**（脚本做不了的）。两者结果应交叉核对。

## 边界（不做的事）

- ❌ 不编造违规项 —— 没有依据的词不得报违规
- ❌ 不提供规避审核的写法（谐音、拼音、拆字绕开检测）—— 属违规协助
- ❌ 不修改商品实质信息（价格、成分、规格）
- ❌ 不评判商品质量，不构成法律意见
- ❌ 平台规则多变，本预审**不能替代**平台官方审核结果

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "platform": "淘宝",
  "category": "化妆品",
  "text": "【全网最低价】医美级精华液，100% 彻底淡化痘印，效果最好的抗敏修复神器！国家级实验室研发，独家配方，销量第一。加微信 xxx 领取试用装，扫码进群更优惠。本品适用于各类肌肤，无任何副作用。"
}
```

**输出**（脚本实跑，12 项命中）：

| 级别 | 原文片段 | 命中规则 | 建议改法 |
|---|---|---|---|
| 🔴 红线 | 最低价 | 绝对化用语·最高级 | 限时优惠价 ¥XX |
| 🔴 红线 | 100% / 彻底 / 无任何副作用 | 绝对化用语·功效断言 | 实测反馈良好（样本 30 人） |
| 🔴 红线 | 国家级 | 绝对化用语·级别 | 删除级别词，改用客观参数 |
| 🔴 红线 | 独家 / 第一 | 绝对化用语·唯一性·排名 | 删除；有专利可附专利号 |
| 🔴 红线 | 抗敏 | 化妆品·医疗宣称 | 删除医疗表述，改「舒缓」 |
| 🔴 红线 | 加微信 / 扫码 | 淘宝·站外导流 | 删除导流信息，避免扣分 |
| 🟡 警告 | 神器 | 营销强化词 | 保留但加限定语 |

整体判定：**不建议上架**（红线 11 项）。
