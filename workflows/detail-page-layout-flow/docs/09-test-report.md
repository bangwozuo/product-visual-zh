### 失败处理演练

| 情况 | 演练方式 | 结果 |
|---|---|---|
| screens 为空 | 空 screens 输入 | 中止（退出码 1），提示输入缺失 |
| 屏型非法 / 屏高 ≤0 | 构造非法 type/height | 中止并指明第几屏、合法值列表 |
| 合规红线 >0 | 命中屏标「打回改文案」，整体「不可交付」 | 覆盖（逐屏归属逻辑实测） |
| 关键屏版式 FAIL | 判定联动：「不可交付（版式未过）」 | 覆盖（曾实测：字号 26 < 26.25 边界触发 FAIL，修复后通过） |
| 总高 >8000px | 判定分支：超长 + 裁剪建议 | 覆盖（合并卖点→删弱卖点→压 FAQ） |
| 规格屏缺参数 | spec 屏 text 为空 | 标「待补参数」，不编造，人工核对项列明 |
