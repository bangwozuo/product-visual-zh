### 失败处理演练

| 情况 | 演练方式 | 结果 |
|---|---|---|
| batch_size 缺失 | 空 batch 输入 | 中止（退出码 1） |
| 白底质检不合格 | whitebg.json 含「不合格」 | 中止并打印不合格指标 |
| 保真 🔴 需返工 | fidelity 判定含「返工」 | 整批停发，退出码 1（一票否决） |
| 缺陷数未回填 | 去 defects 字段 | 标「待人工清点」，判「待清点后判」，正常退出 |
| 任一级拒收 | found > Ac | 判「❌ 拒收（100% 全检返工）」，行标红 |
| 批量 >35000 | 超表批量 | 标「按 GB/T 2828.1 原表查」 |
