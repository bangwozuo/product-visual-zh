# 使用示例

示例 1 的质检单由 `scripts/run_flow.py` 实跑产生（`examples/output.md` 与 `out/`）；
示例 2–4 为同一链路的代表场景。

---

## 示例 1：批量 500 的完整质检链（实跑）

**输入**（`examples/input.json`）：便携手冲咖啡壶套装（SKU: COFFEE-320ML），批量 500，
晨光场景（upper-left / 3800K / 900×1200），人工清点缺陷 致命 0 / 严重 1 / 轻微 4。

**输出**（实跑，退出码 0）：

| 环节 | 结果 |
|---|---|
| 白底归一（white_bg.py 实跑） | 800×800，五项质检全过 |
| 场景提示词包 | 已生成（图层贴回策略 + 光影四参数 + 商品锁定） |
| 保真校验（fidelity_check.py 实跑） | ✅ 通过（成品取轻度偏色演示图，六维实测） |
| 抽样判定 | n=50：致命 Ac0 见 0 → 收；严重 AQL1.0 Ac1 见 1 → 收；轻微 AQL4.0 Ac5 见 4 → 收 |
| **批判定** | **✅ 接收** |

产物：`out/批量质检单.xlsx` + md + `step1_白底归一/`、`step2_场景合成/`、`step3_保真校验/` 留痕。

## 示例 2：保真一票否决（失败处理路径）

**输入**：场景合成出图后发现壶身八角被 AI 重绘成圆弧，基准图 vs 成品图跑
fidelity_check.py → 结构差异块占比 11.8%（>8%）判 🔴 需返工。

**输出要点**：流程**中止**并打印「该 SKU 整批停止交付，回出图环节」——
保真 🔴 不参与抽样，因为它能一票否决整批。返工方向（保真报告热点区定位）：
八角棱线区域按原图贴回，重出后仅重新跑步骤 3–4。

---

## 示例 3：致命缺陷拒收（拒收路径）

**输入**：批量 800（n=80），抽检发现 1 张主图价格标错（致命级）。

**输出要点**：致命级 AQL=0、Ac=0——**见一即拒**，即使严重/轻微全部为 0，
批判定仍是「❌ 拒收（100% 全检返工）」。价格/文字错误属虚假宣传与交易纠纷红线，
不存在"抽样里只出 1 张应该没事"。全检修正后**重新抽样**，不是把剩下 79 张放行。

---

## 示例 4：缺陷未清点（待清点路径）

**输入**：批量 2000（n=125），`defects` 未回填。

**输出要点**：抽样表照常给出 n=125 与三级 Ac/Re（严重 Ac3、轻微 Ac10），
「抽检发现」列标「待人工清点」→ 批判定「⏳ 待人工清点后判」，正常退出不误报。
人工清点回填后重跑脚本出终判——**宁可挂起，不替人猜数**。

---

*本页示例基于真实业务场景；抽样量与 Ac/Re 以 run_flow.py 实测为准。*
