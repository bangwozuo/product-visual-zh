### 失败处理演练

| 情况 | 演练方式 | 结果 |
|---|---|---|
| 源图路径不存在 | 构造错误路径 | 中止（退出码 1），打印路径 |
| 白底质检不合格 | whitebg.json 判定含「不合格」 | 中止并打印不合格指标与报告路径 |
| 上游退出码≠0 / 产物缺失 | 代码路径：打印 stderr 中止 | 覆盖 |
| 基线表外平台 | platforms 含「京东」 | 该行标「需人工给规格」，其余正常 |
| 示意图绘制异常 | try/except 捕获 | 标「示意图缺失」，不阻塞规格表 |
